A few quick notes to help you get Flock installed and ready.

Install Flock

Pick the device you're using, download its file, and open it once the download completes.

1. Choose your platformWindows uses Flock Setup.exe. Android uses Flock.apk.
2. Download the installerTap or click the platform's download button. Keep the file until installation finishes.
3. Install and openFollow your device's install prompts and open Flock when ready.

Before you install

Only install software you trust and keep your device protected.

Windows installerIf SmartScreen displays a warning, verify the file source before proceeding.
Android APKAndroid may request permission to install apps from your browser. Only allow this for a trusted APK.
Missing download?Check your internet connection and try again. Both installers are served from the Flock v1.0.3 GitHub release.
